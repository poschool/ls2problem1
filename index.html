📚 How This Works

A buffer is a fixed-size block of memory. If a program doesn't check the input size, an attacker can write more data than the buffer can hold.

This overflow can corrupt:

  • Local variables on the stack
  • The saved frame pointer
  • The return address (most critical!)

If the return address is overwritten, an attacker might redirect program execution to malicious code.
